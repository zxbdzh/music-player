# Music Hall

A pure-static, fullscreen immersive music player page: HTML + CSS + [APlayer](https://github.com/DIYgod/APlayer). No build step — just open `index.html`.

[中文](README.md)

## Features

- Fullscreen immersive playback UI with loading animation
- Lyrics and playback controls powered by APlayer
- Zero-dependency static deployment

## Usage

Drop your audio files and lyrics into the `assets/` directories and edit the playlist config in `index.html`.
